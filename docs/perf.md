## Protocol

Window w=256, stride s=1 (second stride on one size where listed). Per cell: 1 warm-up run (kept in the CSV, excluded here) and 5 timed runs, modes interleaved round by round within each (dataset, detector) block, 90 s pause between blocks. `total_s` is end to end (mapping the input included). Medians of the timed runs; speedup = median T1 / median Tp with T1 the C-1 median of the same dataset, detector, window and stride; efficiency = speedup / (ranks x threads). Threshold = 1 - 0.001 quantile of the scores of a fixed 100000-window sample, identical in every mode. `MPI-q-scatter` rows are the scatter input mode; all other MPI rows read the file on every rank. Isolation Forest: features in C, scoring in scikit-learn (`n_jobs` = the thread parameter), no MPI.
